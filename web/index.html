04 // Defense in Depth

Six Guardrails

Analyzed code is never executed. Secrets never leave the machine. Non-TTY and CI environments skip cleanly with exit code 0.

STAGE 01 // INGEST

Diff Quarantine

Splits staged diffs, commit ranges, and stdin into exact 1-indexed hunks with .emcignore filtering, size caps, and untrusted boundary delimiters.

STAGE 02 // REDACT

Local Secret Scrub

Masks Solana 64-byte keypair arrays, Base58 private keys, EVM hex keys, BIP-39 12/24-word seeds, API tokens, and .env credentials before network calls.

STAGE 03 // DETECT

16 Static Detectors

8 Anchor Rust rules (missing Signer, UncheckedAccount, unchecked math, PDA bump, invoke_signed, realloc/close, remaining_accounts, unverified CPI), 4 TS wallet rules, 4 generic smells.

STAGE 04 // VALIDATE

4-Step Quality Gate

Enforces verbatim diff grounding, no-answer-leak checks, independent solvability, ambiguity detection, and injection rejection (1 retry, else dropped).

STAGE 05 // GRADE

Quiz & Rubric Judge

Rich terminal session supporting 5 question types (predict-output, what-breaks-if, consequence, spot-the-bug, explain-back) with a -25% hint ladder.

STAGE 06 // GATE

Leitner & Git Hooks

Updates 5-box mastery in .emc/ledger.jsonl with cross-process OS locking, enforces off | warn | gate modes, and writes Comprehension: X/Y trailers.
