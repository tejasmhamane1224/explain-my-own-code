Architecture

Six deterministic guardrails before every commit

emc never executes analyzed code, never leaks raw keys, and exits cleanly in CI or non-TTY shells.

01 · INGEST

Diff Splitting & Quarantine

Parses staged diffs, commit ranges, and stdin into exact 1-indexed hunks with .emcignore filtering, size caps, and untrusted boundary delimiters.

02 · REDACT

Local Secret Scrubbing

Masks Solana 64-byte keypair arrays, Base58 private keys, EVM hex keys, BIP-39 12/24-word seeds, API tokens, and .env secrets locally.

03 · DETECT

16 Static Risk Detectors

8 Anchor Rust rules (missing Signer, UncheckedAccount, unchecked math, PDA bump, invoke_signed, realloc/close, remaining_accounts, unverified CPI), 4 TS wallet rules, and 4 generic smells.

04 · VALIDATE

4-Step Quality Gate

Enforces verbatim diff grounding, no-answer-leak verification, independent solvability, ambiguity rejection, and injection defense (1 retry, else dropped).

05 · GRADE

Interactive Quiz & Rubric

Rich terminal quiz supporting 5 question types (predict-output, what-breaks-if, consequence, spot-the-bug, explain-back) with a -25% hint ladder.

06 · GATE

Leitner Ledger & Git Hooks

Updates 5-box mastery in .emc/ledger.jsonl with cross-process OS locking, enforces off | warn | gate modes, and writes Comprehension: X/Y trailers.
