Hybrid Security-First Pipeline

emc never executes analyzed code, never sends unredacted diffs, and never hangs in CI or non-TTY shells.

01 Ingest & Encapsulate

Parses staged diffs, commit ranges, and stdin into exact 1-indexed hunks with .emcignore filtering, size caps, and untrusted boundary delimiters.

02 Local Secret Redaction

Scrubs Solana 64-byte keypair arrays, Base58 private keys, EVM 0x hex keys, BIP-39 12/24-word seeds, API tokens, and .env secrets locally.

03 16 Static Detectors

8 Anchor Rust rules (missing Signer, UncheckedAccount, unchecked math, PDA bump, invoke_signed, realloc/close, remaining_accounts, unverified CPI), 4 TS wallet rules, and 4 generic smells.

04 4-Step Quality Gate

Every candidate question passes verbatim diff grounding, no-answer-leak verification, independent solvability, ambiguity rejection, and injection defense (1 retry, else dropped).

05 Session & Hybrid Grading

Rich terminal quiz supporting 5 question types (predict-output, what-breaks-if, consequence, spot-the-bug, explain-back) with a -25% hint ladder.

06 Leitner Ledger & Gate

Updates 5-box mastery in .emc/ledger.jsonl with cross-process OS locking, enforces off | warn | gate commit hooks, and appends Comprehension: X/Y trailers.
